## 1. SVD —— 单侧 Jacobi（Hestenes 法）

**世界顶级来源**：Hestenes (1958) *Inversion of matrices by biorthogonalization*；Golub–Van Loan *Matrix Computations* §8.6（单侧 Jacobi SVD）。

**算法**：从 `B ← A` 出发，反复对列对 `(p,q)` 施加 Jacobi 旋转，使 `B = A·V` 收敛为**列正交**矩阵：

```
zeta = (‖b_q‖² − ‖b_p‖²) / (2·b_p·b_q)        # 令 tan2θ = 1/zeta
t    = ±1 / (|zeta| + √(1+ζ²))               # 小角稳定解；**ζ=0 时须取 ±1，不可取 sign(0)=0**
c,s  = 1/√(1+t²), c·t
b_p ← c·b_p − s·b_q ;  b_q ← s·b_p + c·b_q   # 右乘旋转
V   ← V·J                                   # 累积
```

> ⚠️ **v1.3.11 修复：ζ = 0 的等范数列边界缺陷**
> 原实现写作 `t = Math.sign(zeta) / (|zeta| + √(1+ζ²))`。当两列范数**恰等**（‖b_p‖² = ‖b_q‖²，即 ζ = 0）且内积非零时，
> `Math.sign(0) = 0` ⇒ `t = 0` ⇒ `c = 1, s = 0` ⇒ **旋转退化为恒等**，非对角项永不归零。
> 例：对称阵 `A = [[3,1,0],[1,3,0],[0,0,2]]`（列 0/1 范数均为 √10、内积 6）解析奇异值为 **4 / 2 / 2**，
> 修复前返回 `[√10, √10, 2]` 且 `UᵀU ≠ I`（UᵀU[0][1] = 0.6）。
> 根因：Hestenes 根 `t² + 2ζt − 1 = 0` 在 ζ = 0 时的两个根为 **±1**（45° 旋转，均有效），
> `sign()` 在原点不连续导致取到 0。修复：`t = (zeta >= 0 ? 1 : -1) / (|zeta| + √(1+ζ²))`（与 Jacobi 特征分解 `jacobiEigen` 早已采用的正确形式一致）。
> **该缺陷由「算法库 UI 演示」沙盒预检抓获**：随机矩阵检查触发概率为 0（浮点范数恰等的测度为零），因此 25-seed 扫描与全量自检均从未暴露。

收敛后奇异值 `σ_j = ‖B[:,j]‖₂`，`U = B·Σ⁻¹`（列归一化）。

**硬不变量（三条并列，取最大残差，容差 1e-8）**：

| # | 不变量 | 复算路径 | 类型 |
|---|---|---|---|
| 1 | `‖A − U·Σ·Vᵀ‖ / ‖A‖` | 主实现重构 | 结构自洽 |
| 2 | `σᵢ = √λᵢ(AᵀA)` | **独立**：`jacobiEigen(AᵀA)` 另一算法求谱 | 参照 vs 主实现 |
| 3 | `UᵀU = I`、`VᵀV = I` | 正交性 | 结构不变量 |

**实测残差**：2.4e-15（25 seed 扫描最坏值）。

## 2. LU 分解 —— Doolittle 无主元

**世界顶级来源**：Doolittle (1878)；Golub–Van Loan §3.2。

**算法**：高斯消元同步记录乘子，`L` 单位下三角、`U` 上三角：

```
for k: for i>k: L[i][k] = U[i][k]/U[k][k]; U[i][j] -= L[i][k]·U[k][j] (j≥k)
```

**前置条件**：无主元 LU 要求主元远离 0。测试矩阵取**严格对角占优**（`|aᵢᵢ| > Σ_{j≠i}|aᵢⱼ|`），此时分解数值稳定，主元有界。

**硬不变量（容差 1e-9）**：
- `‖A − L·U‖/‖A‖` 重构
- 结构精确：`L[i][i] = 1`、`L[i][j] = 0 (i<j)`、`U[i][j] = 0 (i>j)`（残差恒 0）

**实测残差**：3.4e-16。

## 3. FFT —— 迭代式 radix-2 Cooley–Tukey

**世界顶级来源**：Cooley & Tukey (1965) *An algorithm for the machine calculation of complex Fourier series*。

**算法**：位反转置换 + `len = 2,4,…,n` 蝶形阶段，每阶段旋转因子递推（`W⁰, W¹, …`，仅一次 sin/cos）。输入 `n` 为 2 的幂，复数表示为 `{re, im}`。

**硬不变量（容差 1e-9）**：
- **参照实现 vs 主实现**：`fft(x) ≡ dft(x)`，其中 `dft` 是同文件的朴素 O(n²) 定义式 `X[k] = Σₙ x[n]e^{−2πikn/n}`。n=16 随机复输入，逐分量最大偏差。

**实测残差**：4.3e-14。

## 4. PageRank —— 幂迭代 + 悬挂节点处理

**世界顶级来源**：Page & Brin (1998) *The anatomy of a large-scale hypertextual Web search engine*；Langville & Meyer *Google's PageRank and Beyond*。

**算法**：有向图 → 列随机转移矩阵 `P`（`P[j][i]` = 从 i 到 j 的概率）；悬挂节点（出度为 0）按 teleport 均匀分布。幂迭代

```
π ← α·P·π + (1−α)·(1/n)·1         # α = 0.85
```

收敛后即平稳分布（`Σπ = 1` 由构造保持）。

**硬不变量（容差 1e-9）**：
- **两条独立路径**：幂迭代结果 ≡ 直接线性求解 `(I − αP)π = (1−α)·1/n`（`solveLinear`）。二者为完全不同的计算路径（迭代 vs 直接解）。

**实测残差**：3.9e-16。

## 5. Dijkstra —— 单源最短路径

**世界顶级来源**：Dijkstra (1959) *A note on two problems in connexion with graphs*。

**算法**：贪心 + 线性扫描取未访问最小 `dist`，松弛其出边。非负权前提。

**硬不变量（容差 1e-12）**：
- **参照实现 vs 主实现**：`dijkstra ≡ bellmanFord`（Bellman–Ford，n−1 轮全边松弛），随机有向图（n=12，密度 0.4，权重 0.5–2.5）。
- 含**不可达节点**：两侧同为 `Infinity` 判等（避免 `∞ − ∞ = NaN`），覆盖图的真实边界情形。

**实测残差**：0（精确相等）。

## 6. Slice sampling —— Neal 步进扩展 + 收缩

**世界顶级来源**：Neal (2003) *Slice sampling*, Annals of Statistics 31(3)。

**算法**（目标对数密度 `logf`，加性常数无关）：

```
Y = logf(x) + log(u),  u ~ U(0,1)            # 水平 ≤ logf(x)（关键：保证 slice 非空）
步进扩展：L = x − U·w, R = x + (w − U·w)，向两侧最多 m 步
收缩循环：x₁ ~ U(L,R)；若 logf(x₁) ≥ Y 接受，否则朝 x 方向收缩区间
```

**硬不变量（容差 0.02）**：
- **目标保真**：对标准正态目标（`logf = −x²/2`，解析均值 0、方差 1），12 个独立 seed（`mulberry32(1..12)`）× N=8000、burn=1000，要求 `max(|E[均值]|, |E[方差] − 1|) ≤ 0.02`。
- **稳健性设计**（v1.3.4 铁律）：蒙特卡洛类不变量必须**多 seed**。12 seed 平均的期望矩估计标准差 ≈ 1/√(8000·12) ≈ 0.0032，实测残差 3.31e-3，余量约 6×。
- ⚠️ **实现教训**：若误写 `Y = logf(x) − log(−log(u))`，水平可高于 `logf(x)` 使 slice 为空 → 收缩循环死循环。正确形式必须保证 `Y ≤ logf(x)`。

**实测残差**：3.31e-3。

## 7. Newton 求根 —— 牛顿-拉夫森

**世界顶级来源**：Newton (1669) / Raphson (1690)；数值分析标准教材。

**算法**：`x ← x − f(x)/f′(x)`，`|f|` 或步长触阈早停。

**硬不变量（容差 1e-12）**：
- `|f(x*)| = 0`（对 `f(x) = x³ − 2x − 5`，解析根 ≈ 2.094551481542327，`x₀ = 2`）。收敛后在另一次独立求值中验证残差——通过仍可能因求值路径相同而自洽，故同时断言根值与解析常数一致（残差量级 8.9e-16 ≪ 1e-12 表明达机器精度）。

**实测残差**：8.9e-16。

## 8. RK4 —— 四阶 Runge–Kutta

**世界顶级来源**：Runge (1895)、Kutta (1901)；经典 ODE 积分器。

**算法**：每步四次斜率评估 `k₁..k₄`，`x ← x + (h/6)(k₁ + 2k₂ + 2k₃ + k₄)`。

**硬不变量（容差 1e-8）**：
- **解析 vs 数值**：对 `dx/dt = λx, x(0) = 1`，解析解 `x(T) = e^{λT}`。λ = −1, T = 1, h = 0.005（200 步），RK4 全局误差 O(h⁴)。

**实测残差**：1.9e-12。

## 9. 二叉堆 + 堆排序（v1.3.9）

**世界顶级来源**：Williams (1964) 二叉堆；Knuth《TAOCP Vol.3 排序与搜索》。

**算法**：小顶堆（数组隐式树，父 `(i−1)>>1`，子 `2i+1/2i+2`）；`heapPush` 上滤、`heapPop` 下滤；堆排序 = 全部入堆后依次弹出得升序。

**硬不变量（容差 0，精确）**：
- **参照实现 vs 主实现**：堆排序输出 ≡ `Array.prototype.sort` 升序（200 个 [−1000,1000] 整数，逐位一致）。

**实测残差**：0（精确）。

**实现教训**：堆元素为数组时（如 `[dist, node]`），JS `<`/`<=` 会走**字符串强制转换**（`[10,x] <= [9,y]` 竟为 true），优先队列序全错——必须传显式 `less(a,b)` 比较器（`a[0] < b[0]`）。这是 v1.3.9 沙盒阶段抓到的第 3 类隐蔽缺陷。

## 13. CSR 稀疏矩阵（v1.3.9）

**世界顶级来源**：稀疏行压缩存储（SciPy sparse / BLAS 生态标准格式）。

## 14. Prim / Kruskal 最小生成树（v1.3.9）

**世界顶级来源**：Prim (1957)；Kruskal (1956)。

**算法**：Prim 稠密版 O(V²)（key 数组 + 线性取最小）；Kruskal 并查集 O(E logE)（路径压缩 + 按权排序）；`bruteForceMST` 枚举全部 (n−1) 边子集的生成树作独立参照（小图 n≤6）。

**硬不变量（容差 1e-9）**：
- **三路交叉**：Prim ≡ Kruskal ≡ 暴力枚举生成树（割集最优性）；大图附结构不变量：生成树边数 = n−1（连通图）

**实测残差**：1.8e-15（小图全枚举）/ 3.55e-15（25-seed 扫描最坏）。

**实现教训**：MST 不变量测试的图生成必须**保证连通**（随机稀疏图 p=0.45 在部分 seed 下不连通 → Prim 提前 break 只得部分生成树、Kruskal `count<n−1`，二者不可比）；正确做法是先建随机生成树再叠加额外边。稳健性扫描初版 `worst=1.0` 即此因，非算法缺陷。

## 17. QR 迭代特征值（v1.3.10）

**世界顶级来源**：Francis (1961) QR 迭代；Wilkinson (1964) 位移策略；Golub–Van Loan《Matrix Computations》§7.5。

**算法**：对称阵经反复 QR 步 `Aₖ₋₁ = QₖRₖ → Aₖ = RₖQₖ`（正交相似变换，保迹保范数）逼近上三角；Wilkinson 位移 μ = 块尾 2×2 的最接近特征值估计 ⇒ **三次收敛**；底子对角可忽略即 deflation 收缩活跃块。与 `jacobiEigen`（旋转法）构成两条**完全独立**的特征值路径。

**硬不变量（容差 1e-9）**：
- **两条独立路径**：QR 迭代特征值 ≡ Jacobi 特征值（8 个 6×6 随机对称阵逐位一致）
- **谱不变量**：tr(A) = Σλᵢ（相似变换保迹）
- 退化用例：重根 `[5,2,2]`、2×2、1×1、秩 1 全 1 阵（λ = 4,0,0,0）

**实测残差**：3.2e-14（25-seed 最坏 3.15e-14，最多 27 步收敛）。

**实现教训（沙盒抓获的真实缺陷）**：初版**完全不收敛**——1799 步后残余子对角仍 ~3.0、残差 1.92。根因：deflation 块定位逻辑把活跃块允许成 **1×1**（`l = n−1` 时尾块仅含自身），此时 Wilkinson 位移施加在 1×1 块上等于恒等操作，迭代空转。修正为标准语义：底子对角 `|M[hi][hi−1]| ≤ tol·scale` 即收缩 `hi`（已收敛出一个特征值），活跃不可约块 `[l..hi]` 保证 size ≥ 2。修正后 ≤27 步三次收敛到位。

## 18. 最大流 Edmonds–Karp（v1.3.10）

**世界顶级来源**：Edmonds–Karp (1972)；CLRS 第 26 章。

**算法**：残量网络上 BFS 找**最短**增广路（边数最少），沿路增广瓶颈容量，直到不存在 s-t 路。容量取整 ⇒ 增广次数 O(VE)。

**硬不变量（容差 1e-9）**：
- **定理级**：**max-flow = min-cut**（Ford–Fulkerson 最大流最小割定理）——暴力枚举全部 2^(n−2) 个含 s 不含 t 的顶点子集之割容量取最小，与算法结果比对

**实测残差**：0（整数容量下精确相等）。

## 20. 强连通分量 Tarjan ≡ Kosaraju（v1.3.10）

**世界顶级来源**：Tarjan (1972)（low-link 单遍）；Kosaraju (1978)（两遍反向图）。

## 33. NUTS 采样器（v1.3.13）

## 35. 泛化 U-turn NUTS（v1.3.14）

**世界顶级来源**：Betancourt (2017, *A Conceptual Introduction to Hamiltonian Monte Carlo*)；Hoffman–Gelman (2014)。

**算法**：在 v1.3.13 的 NUTS 骨架（递归二叉轨迹 + 双平均步长自适应 + reservoir 选态）上，把 U-turn 终止判据从**经典标量内积**升级为**广义逐维速度判据**：
- 经典：`(θ⁺−θ⁻)·p⁺ ≥ 0` 且 `(θ⁺−θ⁻)·p⁻ ≥ 0`（标量内积，各维符号可相互抵消）
- 广义：任一维 i 满足 `(θ⁺_i−θ⁻_i)·p⁺_i < 0` 或 `·p⁻_i < 0` 即判转向

广义是经典的**严格细化**：可捕捉「各维符号不一致、标量总和仍为正」的折叠轨迹——经典判据在此**漏检**，导致轨迹在已折叠区域继续扩展、采样分布被系统性压偏。

**硬不变量（容差 0.06）**：
- **正确性**：经验矩 ≡ 解析（2D 强相关高斯 ρ=0.95，20 seed × 2500 样本池化）
- **语义钉死（确定性）**：4 组手工折叠向量上经典/广义判定与预置结论逐一相符，且**分歧集非空**（证明泛化修正确实改变行为）
- **严格细化（单调性）**：同一批 2122 条轨迹三元组上，广义停止次数（1263）≥ 经典停止次数（591），且「仅广义捕获」672 次

**实测残差**：1.66e-2。

**对照实证**：同一目标上经典判据残差 **2.80e-1**（严重偏置），泛化修正把它压低约 **17×**——量化证明经典判据在强相关目标上的漏检后果。

## 36. NTT 数论变换 + CRT 精确整数卷积（v1.3.14）

**世界顶级来源**：Cooley–Tukey (1965) 的数论对应（NTT）；中国剩余定理（CRT）。

**算法**：迭代 radix-2 NTT（bit-reversal 置换 + 蝶形），模 p 逐点相乘后逆变换。素数选取满足 **p² < 2^53**，使模乘在 IEEE754 双精度下精确、免 BigInt：
- `p1 = 7340033 = 7·2^20 + 1`，原根 3（支持长度 ≤ 2^20）
- `p2 = 23068673 = 11·2^21 + 1`，原根 3（支持长度 ≤ 2^21）

双模结果经 CRT 重组得**精确整数卷积**（真值须 < p1·p2/2 ≈ 8.47e13；输入 < 1e3、长度 ≤ 1e3 ⇒ 系数 < 1e9，余量充足）。

**硬不变量（容差 0，精确一致）**：
- **数论 ≡ 直接**：NTT（模 p）卷积 ≡ 朴素 O(nm) 直接卷积（mod p）
- **数论 DFT 定义式**：NTT 正变换 ≡ 朴素 mod-DFT `X[k] = Σ_t a[t]·ω^{kt}`（0 项不符）
- **CRT 精确性**：双模 + CRT 重组 ≡ 精确整数卷积
- **运行时自验**：素数性与原根阶在检查体内现场验证（`_isPrime` / `_isPrimitiveRoot`）

**实测残差**：0（精确）。

## 37. Hopcroft–Karp 二分图最大匹配（v1.3.14）

## 38. Edmonds blossom：一般图最大匹配（v1.3.15）

**世界顶级来源**：Edmonds (1965, *Paths, Trees, and Flowers*)；Berge (1957) 增广路定理。

**为何必须**：Kuhn / Hopcroft–Karp 只在二分图上成立。一般图存在**奇环**，沿奇环的交替路会在 BFS 交错树中形成「花」（blossom），必须缩并后才能继续找增广路 —— 这是组合优化的经典分水岭。

**算法**：BFS 构造交错树；遇偶环（两端同为偶数层且不同花）时以 **LCA 联动定位花根**、把整段环**缩并**为一个「超级点」（DSU `base` 数组），被缩入的点重新入队（`markPath` 双侧标记）；找到增广路后沿 `p` 指针翻转匹配（`while (v !== -1) { pv = p[v]; nv = match[pv]; match[v] = pv; match[pv] = v; v = nv; }`）。

**硬不变量（容差 0，精确一致）**：
- **绝对 ground truth**：最大匹配数 ≡ **暴力枚举全部匹配子集**（比特掩码回溯，200 图，随机图 4–7 点 4–8 边）
- **匹配合法性**：每点至多一条匹配边（`cnt[v] ≤ 1`）
- **极大性**：每条未被选中的边，其两端至少一端已匹配（否则可扩）
- **二分图退化交叉**：随机构造的二分图上 ≡ `hopcroftKarp`（120 图，后者已独立 ≡ Kuhn）

**实测残差**：0（精确）。沙盒首跑时检查体曾因「每条匹配边被两端各计一次」虚报 826 次违规 —— 与 v1.3.13 的 MCMF 教训同源：**检查体自身的双重计数也是缺陷**。

## 39. Split-radix FFT（v1.3.15）

**世界顶级来源**：Yavne (1968)；Duhamel & Hollmann (1984)。2 的幂长度上已知**最低运算量**档次的 FFT 分解。

**分解式**（共轭对 L 型拆分）：

```
X_k = E[k mod N/2] + W_N^k · A[k mod N/4] + W_N^{3k} · B[k mod N/4]
E = SRFFT(x[2m]) 长度 N/2
A = SRFFT(x[4m+1])、B = SRFFT(x[4m+3]) 长度 N/4
```

递归成本 `T(N) = T(N/2) + 2·T(N/4) + Θ(N)`，比 radix-2 的 `T(N) = 2·T(N/2) + Θ(N)` 少约 20% 实数运算 —— 关键在于奇序号被切成 `4m+1` / `4m+3` 两个**共轭对**子变换，共享同一组长度 N/4 的旋转因子。

**硬不变量（容差 1e-9）**：≡ 朴素 DFT（`dft`，O(n²)）≙ 既有 radix-2（`fft`），N = 2/4/8/16/32/64。

**实测残差**：≡ 朴素 DFT **1.81e-13**；≙ fft(radix-2) **9.33e-15**。

## 40. Stoer–Wagner 全局最小割（v1.3.15）

**世界顶级来源**：Stoer & Wagner (1997, *A Simple Min-Cut Algorithm*)；Gomory–Hu 树的推论。

**为何特别**：全局最小割**无需指定 s/t**。最大邻接序（maximum adjacency ordering）每「相」把与当前集合连边权重之和最大的点加入，该相最后一个加入点的 `ws` 值即为一个候选割；随后把它与前一个点缩并，重复 n−1 相取最小。复杂度 O(n³)，比跑 n² 次最大流小一个量级。

**硬不变量（容差 0，精确一致）**：
- **绝对 ground truth**：≡ **暴力枚举全部 2ⁿ 划分**取最小割（150 图，随机图 4–8 点）
- **独立参照**：≙ **n−1 次 s-t 最小割**（`maxFlowEK`）——无向图上全局最小割必可由「固定源点对全体」的 s-t 割取得（Gomory–Hu 性质）

**实测残差**：0（精确）。

## 41. Gomory–Hu 树（v1.3.16）

**世界顶级来源**：Gomory & Hu (1961, *Multi-Terminal Network Flows*)；奠定「所有点对最小割」可用一棵树紧凑表示。

**为何特别**：单个全局最小割（Stoer–Wagner）只给一个数；**所有点对最小割**的结构由一棵 Gomory–Hu 树给出——n−1 次原图最大流，每步把当前超节点按最小 s-t 割（残差可达集）裂成两半并连一条权为割值的边。性质（laminar 割保证）：任两点 u,v 之间的最小割容量，**恰好等于树中 u–v 路径上的最小边权**。复杂度 O(n·最大流)，远优于跑全部 n(n−1)/2 次最大流。

**硬不变量（容差 0，精确一致）**：
- **绝对 ground truth**：≡ **暴力枚举全部 2^(n−1) 个 s-t 割**（120 图，随机连通图 5–8 点）——对**所有点对**验证「树路径最小边 == 精确最小割」，整数 0 容差

## 50. 拍卖算法解指派问题（v1.3.19）

**世界顶级来源**：Bertsekas (1981, *JOTA*) —— ε-标度价格拍卖，指派/运输问题的分布式原对偶算法；Bertsekas–Castanon (1989) 拍卖–匈牙利混合。

**为何特别**：与第 45 节 `hungarianMaxWeight`（中心化 O(n³) 位势法）解同一问题，但机制完全不同——**无中央拍卖师的价格动态**：未匹配者对当前「效益 − 价格」最高与次高的对象竞价，加价 = 两者之差 + ε，被超出者解放重新进入队列；ε 按相 ÷n 收缩。它是对偶上升的分布式形态，与 Hungarian 构成「原对偶价格机制 vs 中心化位势」的世界顶级双路径。

## 53. Chu–Liu/Edmonds 有向最小树形图（v1.3.20）

**世界顶级来源**：Edmonds (1967) *Optimum Branchings*；Chu–Liu (1965) / Bock (1971) 独立提出；Tarjan (1977) 高效实现。

**为何特别**：此前 52 组图算法全部面向**无向图**或**流/匹配**族；最小树形图（arborescence）补上**有向生成树优化**：给定根 r，为每个非根节点选恰好一条入边，构成以 r 为根、可到达全部节点的有向树，最小化总权。支持**负权**与**平行边**。

**算法**：递归收缩。每轮——① 删去进入根的边；② 为每个非根节点取最小权入边（暂定父边）；③ 在「每点一条出边」的函数图上找有向环；④ 把环缩为超节点，进入该环的边权减去「环内该边终点本轮暂定入边权」；⑤ 对缩并图递归求解；⑥ **逐层展开**：进入边所指的环上节点改用该进入边替换其暂定父边，环上其余节点保留本轮暂定父边。

**硬不变量（容差 0，整数精确）**：
- **≡ 暴力枚举父边组合**：每个非根节点独立选入边 → 判定是否构成以 root 为根的有向树 → 取最小总权；覆盖负权 / 平行边 / 多根 / 不可行实例，25 seed
- **结构自校验**：每个非根节点恰一条入边、从 root 可达全部节点、cost = Σ 父边权（平行边按实际最小权取值）、**输入边序置换不变性**（n≤12 随机置换边序结果不变）
- **稠密应力**：40 实例（n = 7..9，边密度 0.55..0.95，强迫多层嵌套收缩）+ 确定性经典环实例（parent 结构与暴力逐个一致）

**实现要点（沙盒实证教训）**：(a) 迭代式「暂定父边后写覆盖」会丢失**层级展开结构**——高层簇取代低层簇时，被覆盖成员的暂定父边必须回滚到低层选择；改为**递归 + 每层返回最终父边表（chosen map）**的结构化展开，缺陷即消失。(b) 暴力参照在**负权下剪枝失效**（部分代价已 ≥ best 仍可靠负权后缀降到更低），须改用后缀最小剩余权 `minRem` 才安全。(c) 结构校验的平行边权重字典不可后写覆盖（应保留最小权）。

**实测残差**：0（精确）。

## 54. Held-Karp 精确 TSP（v1.3.20）

**世界顶级来源**：Bellman (1962) / Held & Karp (1962) 子集动态规划。

**为何特别**：TSP 是 NP-hard 组合优化的原型问题；此前算法库中的组合算法（匹配 / 流 / 割 / 稳定婚姻）都属多项式可解族，Held-Karp 补上**指数级但精确**的一条：`dp[mask][j]` = 从起点出发、恰好访问集合 mask 并以 j 结尾的最短路径，复杂度 O(2ⁿ·n²)，回溯重构环游。天然支持**非对称**距离矩阵（有向边权）。

**硬不变量（容差 0）**：
- **≡ 暴力枚举 (n−1)! 排列**：对称与非对称距离矩阵双向核对（n ≤ 7，25 seed）
- **环游合法性 + cost 自一致**：环游为覆盖全部节点的哈密顿回路，且各边权累加 = 输出 cost
- **2-opt 局部最优**：输出环游在 2-opt 邻域内无可改进（精确最优解的必要条件，独立路径）
- **≤ 最近邻贪心**：精确解不劣于最近邻启发解（对称距离）

**实测残差**：0（精确）。

## 55. AC-3 弧一致性 + CSP 求解（v1.3.20）

**世界顶级来源**：Mackworth (1977) *Consistency in Networks of Relations*（AC-3）；Waltz (1975) 弧一致性滤波；Sabin & Freuder (1994) MAC（Maintaining Arc Consistency during search）。

**为何特别**：前 54 组都是**数值 / 图 / 组合 / 概率**算法；CSP 补上**约束满足与符号推理**这一全新疆域：AC-3 以弧队列反复消解直到不动点（每个保留值在每条弧上都有支持），再以 MRV（最小剩余值）启发式回溯 + 赋值后全传播（MAC）求一个完整解。这是约束编程、SAT 求解、调度、排班、地图着色的公共底座。

**硬不变量（容差 0，25 实例，n = 4..6 / 域大小 2..3）**：
- **决策 ≡ 暴力枚举**：AC-3 + 回溯判定 SAT ⟺ 暴力枚举全部域组合存在满足解（UNSAT 侧同样核对，双侧对称）
- **解合法性**：SAT 输出的解逐条满足全部二元约束
- **AC-3 不动点**：对一致实例，每条弧两个方向上每个保留值都有支持（逐值验证）
- **不删解值**：SAT 实例中至少有一个暴力解的全部值在 AC-3 后仍存活（消解绝不丢失解）

**实现要点（沙盒实证教训）**：注入 core.js 时曾把「域被擦空 ⇒ 暴力须同为 UNSAT」这一断言误放进 `consistent` 分支，导致 SAT 实例被判失败 —— 属**检查体错误而非算法错误**，再次印证「检查体报红先怀疑检查体」。

**实测残差**：0（精确）。

## 59. Aho–Corasick 多模式匹配（v1.3.22）

**世界顶级来源**：Aho & Corasick (1975) *Efficient string matching: an aid to bibliographic search*（SIAM J. Comput. 14(1)）；亦为 GNU grep、Snort、DNA 序列扫描、编辑器增量语法高亮、以及现代全文检索分词层的公共底座。

**为何特别**：此前字符串族只有 KMP（单模式线性）与后缀数组（全文索引）；Aho–Corasick 补上**多模式同时匹配**：一次扫描 O(\|text\| + \|matches\|) 输出**全部**模式的所有出现位置，把 m 个 KMP 的 O(m·n) 降到近线性。

**算法**：① 建模式集 trie；② BFS 构造 failure link `fail[u]` = u 代表串的最长真后缀且在 trie 中；③ `out[u]` = u 的全部后缀模式（沿 fail 链汇合）；④ 扫描时沿字符走 trie，失配沿 fail 链回退，命中 `out[u]` 即报告。

**硬不变量（容差 0，整数/集合精确）**：
- **匹配集 ≡ 暴力**：每个起点 × 每个模式逐字符比较（15 seed × 字母表 {ab, abc} + 重叠模式族 a/aa/aaa/aaaa/aaaaa/ba/aba/ababa + 5 个大规模实例 20 模式 × 200 字符）
- **fail 深度严格递减**：`depth(fail[u]) < depth(u)`（BFS 良构）
- **转移 ≡ 最长后缀**：自动机转移目标 = `repr[u]+c` 的最长后缀且在 trie 中（逐状态 × 逐字符暴力核验）
- **out ≡ 后缀模式集**：每个状态输出的模式集合 = 全部以其代表串为后缀的模式

**实现要点（沙盒实证教训）**：BFS 构造 failure link 时若把 root 的子节点在**循环内外各入队一次**，每个状态会被处理两次，`out[u]` 被 concat 两遍 → **匹配集出现重复**（确定性 bug）。另一次教训：暴力求「最长后缀」时 `substring(L)` 的 L 是起始下标，L=0 才是整串（最长）——循环方向反了会让期望值恒为 root。

**实测残差**：0（精确）。

## 60. CDCL SAT 求解器（1UIP 子句学习）（v1.3.22）

**世界顶级来源**：Marques-Silva & Sakallah (1996) *GRASP—A search algorithm for propositional satisfiability*；Moskewicz et al. (2001) *Chaff: An Efficient SAT Solver*（Chaffing 前身）；现代 MiniSat / CaDiCaL / Kissat 的共同骨架；也是形式化验证、定点证明、符号执行、Tarski 决策问题量词消去、2-SAT/差分逻辑的公共底座。

**为何特别**：此前符号推理族只有 2-SAT（`twoSat`，P 类）与 AC-3+CSP（搜索 + 传播）；CDCL 把**子句学习**引入 —— NP 完全的 SAT 求解从「指数回溯」升级为「传播 + 学习 + 非时序回溯」，并直接对应现代求解器（Mathsat、Z3 的 SAT 后端）。

**算法**：① watched literals 单元传播（两个 watch 被违反时另寻非假文字，否则单元/冲突）；② 1UIP 冲突分析（沿 trail 逆序做分辨率消去，直到当前决策层只剩一个文字）；③ 学习子句回溯到其**第二高层**并断言首文字（非时序回溯）；④ VSIDS 活动度启发选分支变量。

**硬不变量（容差 0）**：
- **决策 ≡ 暴力 ≡ 第二实现**：SAT/UNSAT 判定与暴力枚举 2ⁿ 全部真值指派一致，且与**纯 DPLL**（无学习，仅单元传播 + 分支）一致（15 seed × nv 6..12 × ratio 2.0..5.5 + 8 个相变区实例 nv 13..15 × ratio 3.6..5.2）
- **模型合法**：SAT 时输出的模型逐子句满足
- **学习子句被原公式蕴涵**（CDCL 正确性的核心充要条件）：暴力枚举**全部**满足赋值，每一个都必须满足每一条学习子句（若违反则子句学习破坏了等价性）
- **鸽巢原理经典压力实例**：PHP(p, p−1 洞) 必 UNSAT —— PHP(3→2)/PHP(4→3)/PHP(5→4) 用暴力 2ⁿv 核对；**PHP(6→5)（nv=30，2³⁰ 暴力不可行）用 CDCL + 纯 DPLL 双实现互证**，CDCL 仅 157 次冲突即判定 UNSAT

**实现要点（沙盒实证教训）**：注入 core.js 时 `_bwtTables` 的字符表 `keys` 逐位置 push **未去重** → `C` 表被重复计数、FM 检索全错（沙盒版用 `Object.keys(freq)` 故未暴露）——**沙盒与注入实现结构不同时，必须让注入代码重跑同一套不变量**。另：`analyze` 中 trail 逆序扫描必须显式越界判错，不能静默降级返回坏子句。

**实测残差**：0（精确）。

## 61. Burrows–Wheeler 变换 + FM-index（v1.3.22）

**世界顶级来源**：Burrows & Wheeler (1994) *A block-sorting lossless data compression algorithm*；Ferragina & Manzini (2000) *An introduction to the Burrows–Wheeler transform and its applications*；亦为现代压缩索引（bzip2 块排序、suffix array 索引、二叉 FM-index）、基因组的 PopIndex/twins、四叉树/定位-索引混排的统一底座。

**为何特别**：v1.3.21 刚补的后缀数组是**索引构造**手段；BWT 把文本变成**可自索引的乱序字节流**（压缩 + 定位两种能力合一），FM-index 则实现了「任意模式 O(m) 计数、O(m + occ) 定位」的精确子串检索，且内存 O(文本/采样率)。**本组直接复用已验证的 Manber–Myers 后缀数组**构造 BWT 列（零重写 + 集大成）。

**算法**：BWT 列取「按后缀排序的每个后缀的前一字符」；`C[c]` = 字典序小于 c 的字符总数，`occ(c, i)` = 前 i 位中 c 的出现次数；**LF-mapping** `LF(i) = C[c] + occ(c, i)` 给出后缀连接，逆变换 O(n) 重建原文；FM-index 的 backward search 从模式末字符起反复 `sp = C[c] + occ(c, sp)`、`ep = C[c] + occ(c, ep)` 收窄到后缀区间 `[sp, ep)`。

**硬不变量（容差 0，字符串精确）**：
- **BWT 列 ≡ 暴力**：枚举全部 n 个循环移位、字典序排序、取最后一列（15 seed × 三类输入 + 6 个长串/周期串（150..250 字符、`ab`/`abc`/`aa` 高频重复）+ 9 个边界串（空串 / 单字符 / 全同 / 周期））
- **逆变换 ≡ 原文**：LF 迭代 n 次后重建的字符串 = 原串 + 哨兵
- **LF 为置换**：LF 映射无重复（自索引必要条件）
- **occ 语义**：`occ[c][i]` = BWT 前 i 位中 c 的个数（逐位暴力核验）
- **backward search ≡ 暴力 ≡ `kmpSearch` ≡ `saSearch`**：出现次数与全部起始位置四路一致

**实测残差**：0（精确）。
